# apoio-do-bairro
Apoio do Bairro

Projeto para reunir contatos oficiais e avisos verificados do bairro em uma página simples para celular.

Funções previstas





Consultar contatos sem cadastro.



Ler avisos verificados.



Ver telefone e fonte de cada contato.

Tecnologias previstas

Angular, TypeScript, HTML, CSS e PostgreSQL no Supabase.

Situação atual

O projeto está na fase de protótipo. O site ainda será desenvolvido.
